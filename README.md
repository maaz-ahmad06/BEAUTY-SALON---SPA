# 🌸 Aura Spa & Salon

> A premium, 100% responsive luxury frontend website built with HTML, CSS, and JS, featuring gorgeous custom animations and an elegant preloader.

---

### ✨ Features
* 🌟 **Luxury Gold-Dark Theme**: Premium Obsidian black & champagne gold palette.
* ⏳ **Elegant Preloader**: Smooth logo pulse & loading bar fading out after 2.5 seconds.
* 📱 **100% Responsive**: Tailored layouts for Mobile, Tablet, Laptop, and 4K displays.
* 🎭 **Scroll Reveals**: Graceful Intersection Observer entrance transitions.
* 💳 **Interactive Booking**: Sleek form validation with instant success popup.

---

### 🛠️ Tech Stack
* 🌐 **HTML5** (Semantic layout)
* 🎨 **CSS3** (Glassmorphism, custom keyframes, variables)
* ⚡ **Vanilla JS** (Observer API, dynamic sliders, form states)
* 🏷️ **FontAwesome 6** & 🔤 **Google Fonts**

---

### 🚀 Quick Start
1. Clone the project:
   ```bash
   git clone https://github.com/maaz-ahmad06/BEAUTY-SALON---SPA.git
   ```
2. Open `index.html` directly in your web browser.

# Aura Spa & Salon - Premium Responsive Website

A stunning, state-of-the-art, and 100% responsive frontend landing page built for **Aura Spa & Salon**. It features an elegant dark-gold luxury aesthetic, modern transitions, a custom load preloader, scroll-reveals, and booking validation.

---

## ✨ Features

- **Luxury Gold & Obsidian Theme**: Curated dark theme palette matching high-end beauty and wellness spas.
- **Custom Preloader**: An interactive logo animation and progress bar overlay that displays for 2.5 seconds on initial load, transitioning out with a smooth scale-fade animation.
- **Glassmorphic Sticky Navigation**: A modern header that blurs and adapts with a border glow upon scrolling down.
- **Intersection Observer Scroll Reveals**: Graceful, light-weight entrance transitions (fading, sliding up, sliding left/right) as items enter the viewport.
- **Responsive CSS Grid & Flexbox**: Optimized to fit every screen size perfectly (Mobile, Tablet, Laptop, and 4K displays).
- **Interactive Review Carousel**: Custom-built automated review slider that updates reviews dynamically or via user indicators.
- **Booking & Appointment Form**: Clean glassmorphism layout with client-side JavaScript validation (email formatting, date validations, error feedback).

---

## 🛠️ Technologies Used

* **Structure**: HTML5 (Semantic tags)
* **Styling**: Vanilla CSS3 (Custom keyframes, variables, layouts, and responsive queries)
* **Interactivity**: Pure Vanilla JavaScript (Intersection Observer API, custom event listeners, timers)
* **Assets**: Premium FontAwesome Icons, Cormorant Garamond & Montserrat Google Fonts

## 🚀 How to Run Locally

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/your-username/beauty-salon-spa.git
   cd beauty-salon-spa
   ```

2. **Open the Project**:
   - Double click `index.html` to open it in your browser.
   - Or, run a local web server of your choice:
     ```bash
     # If you have Node.js / npm:
     npx serve .
     
     # Or using Python:
     python -m http.server 8000
     ```

3. **Navigate to browser**:
   Visit `http://localhost:8000` (or the port specified by your local server).
